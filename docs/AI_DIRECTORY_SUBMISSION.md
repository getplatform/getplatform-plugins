## Submission Checklist

For each product, prepare:

- [ ] Product name
- [ ] One-line description (< 160 chars)
- [ ] Long description (200-500 words)
- [ ] Logo (PNG, 512x512 recommended)
- [ ] Screenshot(s) of the product
- [ ] Pricing info (Free tier, paid plans)
- [ ] Category/tags
- [ ] Website URL
- [ ] Demo/video link (if available)

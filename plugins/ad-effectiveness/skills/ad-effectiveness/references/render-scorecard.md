# Right-Brain / Left-Brain Render Scorecard

Score every rendered ad shot — AI-generated (Higgsfield, Veo, Runway, Sora) or filmed —
before accepting it. Grounded in Orlando Wood's left/right-brain creative features (System1
Group), the concrete mechanism behind the Fame–Feeling–Fluency framework.

## Why this scorecard exists

System1's data: **Feeling is the only brand metric that predicts future market share.**
Right-brain creative features build Feeling; left-brain features suppress it. In System1's
Pinterest study, Pins with above-average right-brain and below-average left-brain features
drove a **90% increase in brand favorability**. So an accepted render is not "technically
clean" — it is high on right-brain features AND clean of left-brain penalties.

Source: System1 Group — "Fame, Feeling and Fluency" and "Emotion's role in digital ad
effectiveness"; Orlando Wood, *Lemon* and *Look Out*.

## The scorecard

Score each render. Accept only if it earns the right-brain points AND stays clean of
left-brain penalties.

**Right-brain — want these (1 point each, target ≥4 for a story shot):**
- [ ] A character shows genuine, readable emotion (not a blank or generic face)
- [ ] The setting is a recognizable, relatable real place (not a flat void)
- [ ] There is humour, warmth, or a moment of delight
- [ ] The scene unfolds over time — a beat happens; it is not a static hero shot
- [ ] The distinctive brand assets / Fluent Device are present (recurring character,
      scenario, colour, sound, or motif that carries across executions)

**Left-brain — reject if any appear in a story shot (zero tolerance):**
- [ ] Text overlaying or obstructing the imagery (allowed ONLY on dedicated tagline/end
      cards, never on story beats)
- [ ] Abstracted or disconnected body parts (floating hands, cropped fragments)
- [ ] An isolated product feature shown alone with no human or emotional context
- [ ] A flat, featureless background
- [ ] Any browser, website, screen, UI, or dashboard (pure left-brain — the #1 thing to cut)
- [ ] Rational, product-only messaging inside the story

**Verdict:** a story shot needs **≥4 right-brain points and zero left-brain flags**.
"Clean but flat" (low right-brain score, no penalties) is still a reject — flat renders
waste media spend and train the plan to reward bad creative.

## The text-card exemption

Tagline and end cards are exempt from the "text over imagery" rule. They are the Fluency +
CTA moment, deliberately separated from the emotional beats. Keep them short, keep them off
the story shots, and let the feeling — not an instruction — end the narrative. This is how a
startup reconciles a direct-response CTA (Spike Rating) with brand-building (Star Rating)
without contaminating the emotional arc.

## Reject rules for AI-generated renders

- **Actor/character drift between shots** → regenerate with the full character description
  pasted again verbatim; do not accept a face that changed.
- **Transformation/brand-motif missing** → regenerate; the Fluent Device must be present.
- **Emotion unnameable** → rewrite the prompt (add the emotional beat, the reaction, the
  stakes), do not just re-roll the same prompt.
- **Set/continuity break** → regenerate with the set description pasted again.
- **Garbled on-screen text** → re-roll, or plan a post overlay pass; never ship gibberish
  signage.

## The 3F gate (apply to the whole cut and each shot)

- **Fame:** would a scrolling viewer stop? If flat or stock-like, reject.
- **Feeling:** name the emotion in one word. It must match the shot's intended emotion. If
  you cannot name one, reject.
- **Fluency:** mentally remove the logo — do the tone, colour, motif, or world still signal
  the brand? If a brand moment happens with no distinctive asset present, reject.
